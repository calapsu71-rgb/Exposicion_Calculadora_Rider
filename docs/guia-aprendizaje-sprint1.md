**Centro de Formación:** CTPI - Popayán
**Nombre del Proyecto:** LastBite – Marketplace de Excedentes de Comida Local

## 1. Identificación
- **Fase del Proyecto:** Análisis
- **Competencia:** Recolectar requerimientos del software de acuerdo con las características de negocio.
- **Actividad de Aprendizaje:** Estructurar el repositorio, definir estándares de trabajo ágil y documentar historias de usuario iniciales.

## 2. Presentación
En este primer Sprint, el equipo de LastBite configurará el entorno de trabajo colaborativo utilizando Git y GitHub. Se establecerán las bases documentales del proyecto (Definition of Done y Rúbricas) para garantizar la calidad del software que conectará a comercios locales de Popayán con usuarios interesados en reducir el desperdicio de alimentos.

## 3. Actividades a Desarrollar
1. **Configuración de GitHub:** Inicializar repositorio local, conectar con remoto, crear estructura de carpetas (`src`, `docs`, `.github`).
2. **Definición Documental:** Redactar el `definition-of-done.md` y las plantillas de `historia-usuario`.
3. **Levantamiento de Requisitos:** Redactar las primeras 5 historias de usuario (Registro de Comercio, Registro de Cliente, Publicación de Paquete, Visualización de Catálogo, Reserva de Paquete).

## 4. Evidencias a Entregar
